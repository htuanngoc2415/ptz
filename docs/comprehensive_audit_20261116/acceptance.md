# Predeclared acceptance criteria

Recorded before candidate benchmark results. Compare verified pre-async snapshot A, current async B, isolated optimization C. Same local video frames, target, weights, hardware; sequential trials, 3 repeats minimum. At least 10% improvement in frame-to-RPC responsiveness or ground-truth correct tracking/reacquisition, with no >5% regression in throughput or p95 command latency, zero new safety failures, no increased identity errors. Synthetic or unannotated replay alone cannot pass identity/correct-tracking acceptance. Missing ground truth or physical recenter evidence => NOT PROVEN; restore exact pre-async baseline as default. Report counts and tails; 10% is engineering gate, not significance. No real motor operations. Do not change ReID thresholds, pulse, speed, or overlap. Candidate: batch raw and illumination-normalized crops in one bounded OSNet call, flag default false; score tolerance 1e-4 and unchanged gate outcomes on paired crops required. If unsupported by measurement, retain only as experiment.
